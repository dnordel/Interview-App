# Shared UX Research Templates

This directory contains common template sections inherited by interview and onboarding research overlays.

## Templates

- `findings-record-template.md`

## Change Rule

1. Update shared template content here first for any common-section change.
2. Sync domain overlays in `../interview/` and `../onboarding/` only for domain-specific fields/tasks.
3. Preserve legacy domain filenames and include deprecation notices to avoid link breakage.
