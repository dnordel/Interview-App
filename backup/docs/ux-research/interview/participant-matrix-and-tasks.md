# Participant Matrix and Core Task Set

## Research Segments

| Segment | Experience Definition | Target Count | Primary Risks to Explore |
| --- | --- | ---: | --- |
| New interviewers | 0-3 months conducting structured interviews | 5 | Navigation confidence, rubric comprehension, uncertainty about completion states |
| Intermediate interviewers | 3-18 months of interviewing with recurring rubric use | 5 | Workflow speed, scoring consistency, quality of finalization flow |

## Inclusion Criteria

- Conducts interviewer responsibilities in current role.
- Comfortable using desktop web/desktop app workflows.
- Can complete session in English.

## Exclusion Criteria

- Participated in prior rounds for this same workflow in the last 30 days.
- Deep product implementation knowledge that may bias exploratory behavior.

## Core Task Set (5 Tasks)

1. **Start interview session**
   - Objective: Open a new interview for a test candidate profile and begin note capture.
2. **Find competency rubric guidance**
   - Objective: Locate where scoring criteria are defined before assigning scores.
3. **Score competency #1**
   - Objective: Enter a score and rationale for first competency.
4. **Score competency #2**
   - Objective: Enter a score and rationale for second competency.
5. **Finalize draft summary**
   - Objective: Complete and confirm draft finalization for downstream review.

## Task Order and Counterbalancing

- Maintain fixed order for first pass because this reflects the real workflow dependency chain.
- If running a second exploratory pass, allow free navigation to identify recoverability behavior.

## Data to Capture Per Task

- Completion status (Success / Partial / Fail)
- Time-on-task (seconds)
- Critical error count
- Recovery path taken (if any)
- Participant confidence (1-5)
