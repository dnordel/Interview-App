## Interview-Specific Metric Scope

- **Core tasks included:**
  1. Start interview session
  2. Find competency rubric guidance
  3. Score competency #1
  4. Score competency #2
  5. Finalize draft summary
- **Segment cuts:** New interviewer / Intermediate interviewer
- **Critical error qualifiers:**
  - Incorrect competency score saved without user awareness
  - Finalization blocked due to unresolved validation issues
  - Finalized draft missing required competency details

## Interview-Specific Exit Emphasis

- Prioritize measurable improvement in scoring and finalization time-on-task.
- Treat repeated rubric-discoverability failure as a critical remediation trigger even if completion remains high.
